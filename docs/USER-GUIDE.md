# LittleTodo 快速使用

LittleTodo 将待办保存在本机，适合随手记录负责人、事项和链接。Windows 首版的使用方式如下；macOS 尚待验证。

## 打开并记录

1. 安装并启动 LittleTodo。列表为浮动窗口，可用 **Ctrl + Alt + L**（默认）或托盘「显示待办」唤起并置顶查看。
2. 按 **Ctrl + Alt + N** 打开快速记录，也可以点击列表右上角的 **＋**。
3. 输入一段内容，按需要选择 P1、P2 或 P3。可使用 Markdown，不支持图片。例如：

   ```markdown
   负责人：小明
   - 整理本周进度
   - [相关文档](https://example.com)
   ```

4. 点击**保存事项**，或按 Ctrl + Enter。保存成功后窗口关闭，事项出现在列表中。

若快捷键被占用，可在设置中修改「显示待办」与「快速记录」两个快捷键。关闭输入窗会保留草稿；如果保存失败，输入内容仍留在窗口中。

## 管理事项

- 标题行日期旁用 **‹ ›** 切换前一天/后一天；列表只显示**该日创建**的事项（含已完成）。不能查看未来日期。
- 勾选事项左侧方框表示完成；展开“已完成”可以取消完成。
- 拖动未完成事项调整顺序。内容太长时列表只显示开头，完整内容在详情中。
- 点击事项或 **✎** 打开详情（同时只保留一个编辑窗口；有未保存修改时请先保存再切换事项）；可改内容与优先级、预览 Markdown 后保存；**⎘** 复制到今日（若今日已有相同正文与优先级会询问是否再复制）。
- 历史日的事项不会自动出现在今天；需要时用复制到今日。

## 外观、托盘和提醒

点击列表右上角的齿轮，可以调整背景色、不透明度、两个全局快捷键和通知是否显示事项摘要；设置页显示**数据存储目录**（可一键打开文件夹）及 Agent 只读说明。拖动列表顶部可移动整个窗口。

点击列表右上角的减号，窗口会收起，程序继续在系统托盘运行。**双击**托盘图标可置顶显示列表；右键菜单提供快速记录、设置和退出。也可用快捷键打开输入窗，再点击“显示待办”。

应用运行时，周一至周五 09:00–18:00 的整点会检查未完成事项；没有未完成事项时不提醒。整点提醒使用 Windows **Reminder** 样式：通知会展开并在屏幕上保留，直到你点击 **「知道了」** 或 **「查看待办」**（后者会打开并置顶列表）；通知中心里仍会保留记录。设置里的「测试系统提醒」仅为较长横幅，行为与整点提醒略有不同。

## 数据与隐私

事项与历史保存在设置页所示目录中的 SQLite 文件（`littletodo.sqlite3`），不会自动上传。事项可能包含工作信息；复制数据库或交给 Agent 读取前，请自行确认接收范围。Agent 应以只读方式打开，步骤与提示词见 [AGENT-READONLY.md](AGENT-READONLY.md)；字段与统计口径见 [数据模型](DATA_MODEL.md)。

这是预验收版：安装、卸载后数据保留、桌面层的多屏和系统更新兼容性，以对应版本的[验证证据](EVIDENCE.md)为准。
