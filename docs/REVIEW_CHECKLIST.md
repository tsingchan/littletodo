# LittleTodo 设计审查

1. 显示桌面后仍可见是否在Windows/macOS分别实测，还是仅用非置顶冒充桌面层？桌面层会不会阻止点击编辑和键盘焦点？
2. 数据库失败、重复点击、两个窗口同时保存或迁移中断时，会不会先关窗、重复写入或丢失新内容？
3. 任务完成后取消、跨日未完成、时区变化后，日报是否错误使用当前状态还原历史，或每天复制导致重复计数？
4. 工作日/无任务/休眠/重启/时钟回拨是否导致连发，退出后是否还有未经授权的系统后台任务？
5. Markdown、URL和通知正文能否触发脚本、任意协议或远程请求，真实工作数据是否进入日志/仓库？
6. 长行、长列表、中文、多屏与透明度极值下，是否出现横向滚动、无法拖动或看不见且无法恢复？
7. “轻量”是否有发布模式实测，是否漏算WebView运行时、安装依赖、签名/公证与两系统安装证据？
8. Agent只读连接是否真只读，活动库备份是否一致，旧版程序是否可能写坏新版schema？
