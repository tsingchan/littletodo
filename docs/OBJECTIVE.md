# LittleTodo 目标与验收

基线：2026-10-28；列表窗口与双快捷键重基线：2026-10-29；按日浏览与复制到今日：2026-10-29；复制确认、单一详情窗与数据目录：2026-10-29。阶段：Windows V0.4.6 预验收。

## 目标与范围

面向个人的轻量纯客户端，快速记录事项，桌面持续查看与处理，本地数据可供后续 Agent 只读分析、形成日报。

首版：Windows 与 macOS，全局快捷键（显示待办、快速记录）、浮动待办列表、Markdown 详情、P1/P2/P3、完成与排序、SQLite、工作日系统通知、安装包、透明度和背景色设置。
不做：账号、云同步、多人协作、图片/附件、联网 Agent、自动发送日报、云 API、遥测、自动更新。负责人和 URL 首版写在正文，不强制结构化解析。

## 已确认行为

- 未完成事项保留原创建日期，可在列表中用 ‹ › 按日查看；**不会**自动出现在次日列表。可将历史事项**复制到今日**新建一条。
- 待办列表为普通浮动窗口（非贴桌面底层）；可拖动、设置透明度与背景色，通常放在屏幕右上角。通过全局快捷键或托盘「显示待办」唤起时置顶并聚焦，便于在当前工作窗口之上查看；收起后取消置顶。可被其他置顶窗口遮挡，不长期霸占全屏焦点。
- 快速记录与显示待办均支持可配置全局快捷键（默认分别为 Ctrl+Alt+N、Ctrl+Alt+L）。
- 周一至周五，本地时间09:00–18:00整点提醒，含两个端点，每天最多10个时槽。只在设备开机且应用运行时提醒；无可做事项不提醒。
- 关闭界面后缩到托盘/菜单栏并继续运行。托盘右键退出或真正退出后停止提醒。
- 原用户要求事项只有一段 Markdown 内容，不含图片，可包含负责人、事项、URL；优先级只有 P1/P2/P3。

## 验收标准

下列标准包含Windows与macOS的完整目标，尚无任何一项可整体标为PROVEN。Windows局部自动与人工预验收结果见 `docs/EVIDENCE.md`；标为PROVEN必须链接对应平台的实现与证据。

| ID | 可检查结果 |
| --- | --- |
| C1 | 应用运行时，从其他应用按配置快捷键：快速记录窗获得焦点；显示待办快捷键唤起列表并置顶聚焦；重复触发只激活同一目标；冲突有提示和更改入口。 |
| C2 | 输入非空 Markdown 和优先级后保存，SQLite 事务提交成功才关闭输入窗，列表新增一次；重复提交不重复创建，失败保留正文，纯空白拒绝。 |
| C3 | 列表为可拖动浮动窗口；通过快捷键/托盘唤起时可置顶于当前工作区之上，收起后取消置顶；详情和输入窗可正常前台编辑。 |
| C4 | 列表背景色与透明度可修改并持久化；文字和交互保持可辨识，禁止配置成无法恢复的完全不可见；位置重启恢复，多屏移除/DPI改变后不落到屏幕外。 |
| C5 | 每行有完成框、P1/P2/P3、正文前部摘要、右侧笔形入口；长文单行省略，无横向滚动条；多任务纵向滚动，拖动排序时可滚动。 |
| C6 | 勾选完成后持久化完成时间，拖动改变人工顺序且重启保持；优先级不擅自覆盖人工顺序；未完成跨日仍在列表。取消完成及完成区展示方案见待决项。 |
| C7 | 点击内容或笔图标打开详情，支持 Markdown 预览、编辑和优先级修改、保存及关闭；失败保留草稿；未保存关闭有处理入口；陈旧版本不能静默覆盖。 |
| C8 | 本地 SQLite 持久化任务、日期、时间和变更记录，结构及只读查询有文档；重启无丢失；当日新增/完成/日末未完成口径可追溯，跨日不重复创建。 |
| C9 | 工作日09–18整点，仅存在未完成可做事项时发送一次 OS 通知，显示数量和有限摘要；周末、无待办、退出应用不提醒；休眠恢复不连续追发漏掉的多小时提醒。系统拒绝权限或勿扰时不声称已展示。 |
| C10 | 关闭窗口后托盘/菜单栏仍可恢复输入、列表与设置；显式退出释放快捷键和提醒调度；再次启动保留数据。 |
| C11 | Windows 与 macOS 分别完成安装、启动、主要路径、升级与卸载验证；卸载默认保留数据，清除数据需单独明确操作；构建成功不能替代安装验证。 |
| C12 | 无网络主要功能可用；Markdown 不执行 HTML/脚本，不加载图片、远程资源或字体，http/https 链接仅用户点击才打开系统浏览器；通知正文纯文本，提供关闭内容预览能力。 |
| C13 | 发布构建记录安装包大小、安装后占用、冷启动至可输入时间和空闲/详情内存，并与同机便签比较；数值预算待实测后确认，当前不承诺已更轻。 |

## 提议及未知事项

- 建议新事项默认 P2；人工顺序为主；完成事项折叠、可取消完成。待用户确认，不作为已批准要求。
- “可做事项”首版建议解释为全部未完成事项；没有截止时间、阻塞或未来计划功能，不能擅自用 AI 判断某任务不可做。
- “开机时提醒”暂按开机且应用在后台运行理解；是否开机自动启动、是否登录时额外提醒待确认，不默认注册自启。系统关机或显式退出不应被后台任务偷偷重启。
- 默认快捷键、窗口尺寸、透明度范围和具体色板待原型确认。“参考todo”的具体产品未知。
- 支持的系统最低版本、CPU架构、签名证书与 macOS 公证条件未知，选型时补齐。
- 真正桌面层有平台差异；必须先做能力验证，若无法满足需向用户展示限制及替代方案，不降级为普通非置顶窗口后声称完成。
