# LittleTodo 职责边界

以下为计划组件，源码路径在选型落地后确定。

| 组件 | 负责 | 不负责 |
| --- | --- | --- |
| 列表 UI | 完成框、优先级、摘要、省略/滚动、排序手势、编辑入口、颜色设置 | SQL、跨日统计、直接调用OS |
| 输入与详情 UI | 草稿、Markdown安全预览、编辑、提交反馈 | 任意HTML、远程加载、直接读写文件 |
| 应用服务 | 输入校验、写入去重、版本冲突、事务提交后广播 | 桌面层原生API和样式 |
| 领域核心 | 状态/优先级/人工顺序、日期口径、可做事项与提醒规则 | UI、网络、平台SDK |
| SQLite repository | 数据库连接、事务、迁移、事件、查询视图与备份 | 渲染或系统通知 |
| OS adapter | 全局快捷键、桌面层、前台编辑窗、焦点、托盘、外链、通知 | 复制任务状态、决定统计语义 |
| reminder service | 可注入时钟、工作日/时槽判断、去重、查询未完成、通知摘要 | 绕过勿扰、退出后唤醒、追发所有漏掉时槽 |
| Agent分析使用者 | 根据DATA_MODEL只读查询，手动形成日报 | 默认写库、改schema、上传工作数据 |

UI → 最小本地命令接口 → 应用服务 → 领域核心 / repository → SQLite。
事务提交成功 → 返回结果及广播 → 各窗口刷新。提醒复用任务查询，不维护第二份任务状态。

若选 Tauri，本地服务、数据库与 OS 适配放 Rust 侧。前端不开放任意 SQL、shell、文件路径访问。桌面列表与前台编辑窗必须分开处理焦点和窗口层级。
