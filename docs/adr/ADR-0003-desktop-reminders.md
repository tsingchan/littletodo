# ADR-0003: 桌面窗口、后台生命周期与提醒

- Status: Accepted for Windows V0.1.0; macOS adapter pending
- Date: 2026-10-28

## Context

用户已确认贴桌面、显示桌面仍可见、可调透明度/背景色，关闭界面留托盘；工作日09–18整点、有未完成才提醒；真正退出后不提醒。

## Options

1. 普通非置顶窗口：实现容易，但不满足显示桌面仍可见，不作为满足需求的替代实现。
2. 平台桌面层适配 + 独立前台编辑窗：符合目标，但需要两平台验证和受控原生能力。
3. OS计划任务/外部服务：可能退出后运行，复杂且违背当前退出语义，不纳入首版。

## Decision

实现默认Ctrl+Alt+N（可改），新任务P2，完成区折叠，支持取消完成；列表背景透明度0.4–1.0。工作日09–18整点使用60秒宽限，不补发已错过小时；无未完成不通知。配置不默认注册开机自启。窗口关闭时隐藏，托盘显式退出才终止。桌面宿主重启时检测父窗口有效性并尝试重新挂载，失败退为可操作的普通窗口并显示状态，不宣称仍贴桌面。

内存调整：当前安装版闲置进程组私有内存约226 MiB，且预创建快速输入、详情和设置窗口可能积累WebView。改为按需创建快速输入，成功保存或妥善保留草稿后销毁；详情/设置在安全关闭后销毁。主列表隐藏时仍保留以支持托盘和提醒。窗口创建竞态用单一原子门控制，保存/草稿必须先完成再释放窗口；更改后须比较相同条件的进程组内存并回归快捷键、草稿、详情与退出保护。此方案是优化候选，效果须实测。

建议第2种；用户确认的产品语义不再作为待选，平台实现路径仍待验证。
工作日每整点检查一次，只有未完成才发送；同一安装实例避免重复运行；持久化时槽记录避免重启重发。
睡眠漏过不逐个补发，恢复后等待下一整点；若恢复恰在时槽边缘允许一次短宽限的建议需实现前定义（建议60秒）。
“开机时”不等于已授权注册开机自启，需确认。
无截止日期/阻塞状态时，所有未完成即“可做”，不引入不可解释的智能过滤。

## Consequences

通知由系统决定是否展示；发送成功与用户看到是两件事。通知提交与数据库不能原子提交；建议先占用时槽再发送，接受极端崩溃漏一条，避免连发。
时区变化重新计算下一本地整点；时槽键包含当地日期/小时与时区偏移，时间回拨的重复策略需测试。
透明度作用范围和文字可读性需原型评审，托盘提供恢复可见设置入口。
