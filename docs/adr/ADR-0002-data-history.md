# ADR-0002: SQLite单库与可追溯任务历史

- Status: Accepted for Windows V0.1.0
- Date: 2026-10-28

## Context

用户明确要求SQLite且便于Agent分析每日数据。只保留当前行无法准确还原过去某天的未完成状态；每天复制事项会重复计数。

## Options

1. 每天独立数据库或每天复制任务：看似直接，但跨日身份、排序和统计容易分裂。
2. 单库任务当前表 + 事务内追加事件 + 只读查询：状态查询简单且可追溯，增加事件与迁移约束。

## Decision

进入分阶段实现：单库tasks+task_events+settings+reminder_slots。默认P2、人工全局顺序、完成事项可折叠及取消完成。新库编号迁移v1，拒绝写入未知高版本库；预留备份接口。具体字段以src-tauri/migrations/001.sql为实现合同。所有应用写入串行事务，command_id全命令幂等，编辑/完成采用version条件防覆盖。事件保留实际UTC和单调有效UTC，避免时钟回拨破坏事件顺序；真实跨时区历史仍需解释当地日期口径。

建议第二种，详见DATA_MODEL。跨日延续原任务及原创建日期为用户已确认事实；事件结构、保留期限和查询接口仍为设计提议。不生成真实数据库。

## Consequences

事件与状态在同一事务提交；保留历史会保留旧正文，需在产品中说明，后续清除/保留策略需明确设计。
不默认向Agent开放写连接；备份不能仅复制可能仍有WAL写入的主文件；迁移前备份并验证恢复。
